### Индивидуальное задание по Преддипломной практике

Индивидуальное задание заключается в участии в выполнении следующих видов работ:  
1)	Анализ технического оснащения предприятия компьютерной техникой (ознакомиться с должностными инструкциями и провести анализ структуры подразделения, провести анализ технических возможностей компьютерной техники в подразделении, ознакомиться с типами и конфигурацией компьютеров и оргтехники, задействованных на предприятии, знать архитектуру сети на предприятии, если она есть)  
2)	Анализ программного обеспечения (ознакомиться с существующими системами защиты данных, ознакомиться с операционной системой, установленной на предприятии, провести анализ возможности работы операционной системы для реализации дипломного проекта)  
3)	Обоснование выбора задачи для автоматизации (проанализировать исходные данные, предложить способы автоматизации работы предприятия в рамках темы своего дипломного проекта)  
4)	Постановка профессиональной задачи, определяемой темой дипломного проекта (обследовать предметную область поставленной профессиональной задачи в рамках темы дипломного проекта, выделить информационные объекты, необходимые для решения профессиональной задачи)  
5)	Технология решения поставленной профессиональной задачи (проанализировать этапы решения задачи, разработать программный продукт по требованию заказчика, разработать сопроводительную документацию к программному продукту, предложить варианты обучения персонала по работе с программным продуктом)
	
Все пункты задания должны быть представлены в отчете по преддипломной практике.
