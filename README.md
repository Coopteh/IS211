# Вопросы к экзамену
1
Что такое информационная система?
Комплекс взаимосвязанных компонентов для работы с информацией. Информационная система включает в себя оборудование, программное обеспечение, людей и процессы для сбора, хранения, обработки и передачи информации.

2
Какая основная цель внедрения информационной системы?
Автоматизация и оптимизация бизнес-процессов. Основной целью внедрения ИС является повышение эффективности работы компании через автоматизацию и оптимизацию процессов.

3
Какой компонент информационной системы отвечает за обработку и хранение данных?
Программное обеспечение - Программное обеспечение включает базы данных и приложения, которые управляют хранением и обработкой информации.

4
Что из перечисленного является примером прикладного программного обеспечения?
Операционная система | Система управления базами данных | Сервер 
Правильный ответ: Система управления базами данных. СУБД — это прикладное программное обеспечение, предназначенное для управления и обработки данных в ИС.

5
К какому компоненту ИС относятся серверы и сетевое оборудование?
Программное обеспечение | Аппаратное обеспечение | Люди | Процессы
Правильный ответ: Аппаратное обеспечение. Серверы и сетевое оборудование являются частью аппаратного обеспечения, обеспечивающего физическую основу для работы ИС.

6
Что является ключевым принципом методологии Agile?
Линейное следование этапам | Непрерывная интеграция | Гибкость и итеративность | Подробная документация
Правильный ответ: Гибкость и итеративность - Agile ориентирован на гибкость и итеративный подход, что позволяет адаптироваться к изменениям и улучшать продукт по мере разработки.

7
Какой из принципов DevOps фокусируется на автоматизации сборки, тестирования и развертывания ПО?
Непрерывная интеграция | Непрерывная доставка | Гибкость | Ретроспектива
Правильный ответ: Непрерывная доставка - Непрерывная доставка включает автоматизацию всех этапов развертывания ПО, что позволяет быстрее и более надежно выпускать обновления.

8
Какой из недостатков каскадной модели наиболее очевиден в условиях быстро меняющихся требований?
Сложность в масштабировании | Высокие затраты на документацию | Низкая гибкость | Высокие требования к автоматизации
Правильный ответ: Низкая гибкость - Каскадная модель имеет низкую гибкость, что затрудняет внесение изменений в проект на поздних этапах разработки.

9
Какую функцию выполняет проектный менеджер в проекте?
Выполняет задачи | Контролирует бюджет | Координирует работу команды | Предоставляет программное обеспечение
Правильный ответ: Координирует работу команды - Проектный менеджер отвечает за координацию работы команды, управление ресурсами и взаимодействие со стейкхолдерами.

10
Какая из перечисленных методологий наиболее подходит для проектов с четкими, неизменными требованиями?
Agile | Scrum | Водопадная модель | Канбан
Правильный ответ: Водопадная модель - Водопадная модель предполагает последовательное выполнение этапов проекта, что делает ее подходящей для проектов с четкими и стабильными требованиями.

11
Дайте определение - что такое конфигурационное управление?
Процесс контроля изменений и сохранения целостности системы. Конфигурационное управление направлено на контроль всех изменений в проекте и поддержание его целостности.

12
Какой основной процесс конфигурационного управления позволяет вернуться к предыдущим версиям проекта?
Идентификация конфигурации | Аудит | Контроль версий | Отчётность
Правильный ответ: Контроль версий - Контроль версий позволяет сохранять и отслеживать изменения в проекте, предоставляя возможность вернуться к любому предыдущему состоянию.

13
Какая система контроля версий является распределённой?
CVS | SVN | Git | Mercurial
Git — это распределённая система контроля версий, в которой каждый пользователь имеет полную копию репозитория.

14
Что делает команда git init?
Инициализирует новый репозиторий | Добавляет файлы в индекс | Создаёт коммит | Просматривает историю изменений
Инициализирует новый репозиторий - git init создаёт новый репозиторий в текущей директории, начиная отслеживать файлы проекта.

15
Напишите команду, которая используется для добавления файлов в индекс в Git?
git add - команда git add подготавливает файлы для коммита, добавляя их в индекс.

16
Какая команда используется для создания коммита в Git? Запишите правильный синтаксис употребления команды.
Правильный ответ: git commit -m "какой-то комментарий"
Команда git commit фиксирует изменения в проекте, добавляя их в историю репозитория.

17
Что такое ветка в Git?
Файл с изменениями в проекте | Отдельная линия разработки | Компонент конфигурационного управления | Снимок состояния проекта
Правильный ответ: Отдельная линия разработки. Ветка — это параллельная линия разработки, в которой можно работать независимо от основной ветки проекта.

18
Что происходит при слиянии (merge) в Git?
Создаётся новый коммит | Добавляются файлы в индекс | Объединяются изменения из разных веток | Просматривается история коммитов
Правильный ответ: Объединяются изменения из разных веток

19 
Что такое слиянии (merge) в Git?
Слияние — это процесс объединения изменений из разных веток в одну.

20
Какая команда отображает историю изменений в Git?
git status | git log | git add | git pull
Правильный ответ: git log Команда git log выводит на экран историю всех коммитов, сделанных в репозитории.

21
Что делает команда git init? 
Создаёт новый удалённый репозиторий | Инициализирует новый локальный репозиторий | Добавляет файлы в индекс | Отправляет изменения в удалённый репозиторий
Ответ: Инициализирует новый локальный репозиторий
Команда git init создаёт пустой репозиторий в указанной папке и начинает отслеживать изменения.

22
Какая команда добавляет файлы в индекс для последующего коммита? 
git add | git commit | git push | git log
Ответ: git add 
git add добавляет файлы в область подготовленных изменений для последующего коммита.

23
Для чего используется команда git commit -m "сообщение"? 
Для инициализации репозитория | Для отправки файлов в удалённый репозиторий | Для фиксации изменений с описанием | Для добавления файлов в индекс
Ответ: Для фиксации изменений с описанием
git commit -m сохраняет текущее состояние проекта с описанием изменений, которое указывается в кавычках.

24
Какую команду нужно выполнить для проверки настроек Git (имя пользователя, email)? 
git status | git config --list | git remote -v | git add .
Ответ: git config --list
Команда git config --list выводит все текущие настройки Git, включая имя пользователя и email.

25
Какую команду используют для отправки изменений в удалённый репозиторий? 
git push | git fetch | git clone | git pull
Ответ: git push
Команда git push отправляет изменения с локального репозитория в удалённый, что позволяет синхронизировать их с сервером.

26
Для чего используется команда ssh-keygen -t rsa -b 4096 -C "ваш.email@example.com"? 
Эта команда генерирует пару SSH-ключей, которая необходима для безопасного подключения к удалённым репозиториям.

27
Что произойдёт, если команда git log не выдаёт никакой информации? 
Коммитов нет | Проект удалён | Файлы не добавлены в индекс | Репозиторий не был инициализирован
Ответ: Коммитов нет
Команда git log показывает историю коммитов. Если в репозитории нет коммитов, команда не выдаст результатов.

28
Какая команда используется для подключения к удалённому репозиторию? 
Ответ: git remote add origin
Команда git remote add origin добавляет удалённый репозиторий с заданным URL и связывает его с локальным репозиторием для дальнейшей синхронизации.

29
Что такое виртуализация?
Создание нескольких виртуальных машин на одном физическом сервере | Создание изолированных контейнеров для приложений | Разделение ресурсов на уровне ядра ОС | Виртуализация сетевых устройств
Правильный ответ: Создание нескольких виртуальных машин на одном физическом сервере
Виртуализация позволяет запускать несколько виртуальных машин (VM) на одном физическом сервере, каждая из которых содержит свою собственную операционную систему.

30
Какой из следующих вариантов лучше описывает контейнеризацию?
Метод создания виртуальных машин с отдельной ОС для каждой | Технология, которая упаковывает приложение и его зависимости в изолированную среду | Процесс распределения ресурсов между несколькими серверами | Подход к резервному копированию данных

Правильный ответ: Технология, которая упаковывает приложение и его зависимости в изолированную среду
Контейнеризация включает упаковку приложения и его зависимостей в контейнеры, которые используют одно ядро ОС и обеспечивают лёгкость и портативность.

31
Какое из перечисленных преимуществ является характерным для виртуализации?
Лёгкость и быстрота запуска | Высокая степень изоляции | Портативность между различными системами | Меньшее потребление ресурсов
Правильный ответ: Высокая степень изоляции
Виртуализация обеспечивает высокую степень изоляции, так как каждая виртуальная машина содержит собственную операционную систему.

32
Какое преимущество контейнеризации по сравнению с виртуализацией?
Более высокая степень изоляции | Меньшее потребление ресурсов | Наличие отдельной ОС для каждого контейнера | Более сложное управление
Правильный ответ: Меньшее потребление ресурсов
Контейнеризация позволяет уменьшить потребление ресурсов, поскольку все контейнеры используют одно ядро ОС и не требуют отдельной операционной системы для каждого контейнера.

33
Какой инструмент используется для управления контейнерами на больших системах?
Docker | Kubernetes | VMware | VirtualBox
Правильный ответ: Kubernetes
Kubernetes используется для управления и оркестрации большого количества контейнеров, автоматизируя такие задачи, как балансировка нагрузки и масштабирование.

34
Какое основное отличие между виртуализацией и контейнеризацией?
Виртуализация использует одно ядро ОС для всех VM, а контейнеризация — отдельные ОС для каждого контейнера | Виртуализация требует больше ресурсов, а контейнеризация — меньше | Контейнеризация не позволяет создавать изолированные среды | Виртуализация менее гибка по сравнению с контейнеризацией
Правильный ответ: Виртуализация требует больше ресурсов, а контейнеризация — меньше
Контейнеризация более эффективна в плане использования ресурсов, так как контейнеры делят одно ядро ОС, в отличие от виртуализации, которая требует отдельную ОС для каждой виртуальной машины.

35
Что представляет собой контейнеризация?
Правильный ответ: Изоляция процессов с использованием общего ядра ОС
Контейнеры используют одно ядро ОС, изолируя процессы внутри контейнеров, что отличает их от виртуальных машин.

36

Команда docker run используется для запуска нового контейнера на основе образа.

37

38

Правильный ответ: Виртуальные машины требуют больше ресурсов
Виртуализация запускает отдельные ОС на каждой виртуальной машине, что требует больше ресурсов, в то время как контейнеры делят одно ядро ОС.

39

40

Правильный ответ: Для полной изоляции приложений с разными ОС
Виртуализация позволяет запускать разные операционные системы на одном сервере с полной изоляцией.

Команда docker volume create создаёт новый том для хранения данных контейнера.

42

Правильный ответ: Быстрое развёртывание и меньшие затраты на ресурсы
Обоснование: Контейнеры требуют меньше ресурсов и быстрее запускаются по сравнению с виртуальными машинами, которые включают полноценные операционные системы.

43
Что означает принцип идемпотентности в автоматизации развёртывания?
Правильный ответ: Операция не изменяет состояние системы при повторном выполнении, если она уже в нужном состоянии
Идемпотентность гарантирует, что повторные выполнения операции не изменят результат, если система уже настроена корректно.

44

Автоматическое управление конфигурациями снижает необходимость ручного вмешательства и делает процессы более предсказуемыми и стабильными.

48

Проверка всех функций веб-приложения после обновления - какой это вид теста?

Что такое CI/CD и в чем цель ее внедрения?

CI/CD (Continuous Integration, Continuous Delivery) — это технология автоматизации тестирования и доставки новых модулей разрабатываемого проекта заинтересованным сторонам (разработчикам, аналитикам, инженерам качества, конечным пользователям и другим).
Цель CI/CD — ускорить обнаружение дефектов, повысить производительность и обеспечить более быстрые циклы выпуска и внедрения ПО.
