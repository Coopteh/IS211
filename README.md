# Индивидуальное задание на УП, ПП 07

Создание концептуальной модели данных:   
- изучите требования к базе данных предприятия производственной практики;
- разработайте концептуальную модель, определив основные сущности и их взаимосвязи;  
- создайте ER-диаграмму.  
Проектирование логической и физической модели данных:  
- переведите концептуальную модель в логическую, определив атрибуты сущностей и установив первичные и внешние ключи;  
- создайте физическую модель, подготовив SQL-скрипты для создания таблиц базы данных с указанием типов данных.  
Выполнение запросов на языке SQL: напишите и выполните следующие SQL-запросы:  
- запрос на выборку данных с использованием JOIN;  
- запрос на вставку новых записей в таблицу;  
- запрос на обновление существующих данных;  
- запрос на удаление записей из таблицы.  
Настройка сетевого адаптера и межсетевого взаимодействия:
- настройте сетевой адаптер для подключения к базе данных;
- проведите тестирование соединения с базой данных, убедившись в корректной настройке.
Разработка политики безопасности для SQL сервера:
- определите роли пользователей и настройте права доступа к базе данных; 
- подготовьте рекомендации по защите базы данных от несанкционированного доступа.  
Мониторинг нагрузки сервера:  
- используйте инструменты мониторинга производительности SQL сервера для анализа нагрузки;
- подготовьте отчет о производительности базы данных с рекомендациями по оптимизации.
