Какое основное отличие между виртуализацией и контейнеризацией?

- Виртуализация использует одно ядро ОС для всех VM, а контейнеризация — отдельные ОС для каждого контейнера 
- Виртуализация требует больше ресурсов, а контейнеризация — меньше 
- Контейнеризация не позволяет создавать изолированные среды 
- Виртуализация менее гибка по сравнению с контейнеризацией
